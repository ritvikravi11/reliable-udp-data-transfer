## Protocols

The project implements three reliable data transfer protocols:

- Stop-and-Wait
- Go-Back-N
- Selective Repeat

## Core Features

- UDP-based file transfer
- Sequence numbers
- Checksums
- Acknowledgements
- Retransmission timers
- Adaptive RTO
- Jacobson/Karels RTT estimation
- Karn's algorithm
- Channel emulation
- Packet loss
- Packet duplication
- Packet reordering
- Packet corruption
- Delay and jitter
- File integrity verification
